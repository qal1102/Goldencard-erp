# GoldenCard ERP Project

GoldenCard là công ty lắp đặt điện mặt trời.

Mục tiêu: xây ERP nội bộ cho quy trình solar, sau đó có thể mở rộng thành SaaS cho các công ty solar và ngành lắp đặt khác.

Người tham gia:
- Anh Hà: Giám đốc, người duyệt dự án
- Anh Tân: kĩ sư trưởng, tư vấn, chốt hợp đồng, giám sát thi công, liên hệ khách
- KTV: khảo sát, thiết kế bản vẽ, lắp đặt
- QA: lead dev/PM nội bộ

Tech stack:
- Next.js 15 + TypeScript
- PostgreSQL/Supabase
- Drizzle ORM
- TanStack Query
- shadcn/ui + Tailwind CSS
- Auth.js
- Cloudflare R2
- Vercel
- n8n
